# Revisões da v0.3.0

Data: 02/11/2026. Revisões locais em duas passagens pelo implementador;
não constituem aprovação independente. Contratos conferidos no código do
ai-memory v3.3.1 (`1c506228b701f4496d3d9af6f00180749e0563d1`).

## Code review

Foram percorridos transporte, geração da conexão, ciclo dos trabalhadores,
rotas/escopos, identidade, estado de renderização e integração com AppKit.

| Achado | Correção e evidência |
| --- | --- |
| HTTP 200 incompatível poderia parecer lista vazia | Validação de formato antes de publicar resultados; teste `malformed_success_is_an_error_not_an_empty_list` |
| Consulta em andamento podia retornar após reconexão | Captura da geração sob lock da configuração, verificação antes/depois do HTTP e no consumidor; teste com barreira `changing_connection_discards_in_flight_result` |
| Backlink de outro projeto podia abrir no projeto atual | Coordenadas do registro preservadas; teste `cross_project_reference_uses_its_actual_coordinates` |
| Saúde da Central não respeitava Pausar tela | Snapshot visual sincronizado com o mesmo ciclo do painel; coletor/menu continuam independentes |
| Literal de espessura ambíguo no grafo | Tipo f32 explícito; Clippy sem warnings |

Não há POST/DELETE ou consumo de handoff nesta fase. Erros de rede/HTTP não
reproduzem corpos; redirects/proxies desabilitados; URLs e caminhos são
construídos por segmentos, com rejeição de traversal; token não é serializado.
A ordem de locks não introduz espera circular e a fila manual é limitada.

## Bug review

| Achado | Correção e evidência |
| --- | --- |
| Listas de páginas/relações poderiam renderizar todo o inventário de uma vez | Paginação local de 100, com contagem; grafo validado até o limite upstream |
| Corpo de página muito grande poderia bloquear o layout | Prévia de 100 KiB com aviso; corte em fronteira UTF-8 testado |
| Estado ausente/negado podia ser interpretado como normal | Erros explícitos, valores desconhecidos como travessão e testes de 403/campos opcionais/staleness |
| Estado de consulta antigo após trocar aba/escopo/conexão | Ticket invalidado e resultado limpo; reset exercitado em teste de UI |

Smoke nativo com servidor HTTP sintético: Saúde com alerta de consolidação,
seleção de projeto, sessão/tokens, timeline/expansão, páginas, leitura e
histórico/diff. Inspeção por acessibilidade e screenshot comprovou controles e
texto legíveis. O coletor Docker permaneceu somente leitura; dados reais não
foram incluídos no pacote ou nos artefatos públicos.
