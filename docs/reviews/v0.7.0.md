### Limitações de host e riscos externos

- O Plasma 5.27 prefere o `IconPixmap`, então lá aparece o pulso colorido e o
  ícone simbólico nunca. O app publica os dois (`src/tray.rs:261-280`).
- O Waybar 0.9.17 não recolore o ícone simbólico; o cinza `#808080` mantém
  contraste ≥ 3:1.
- No macOS claro com papel de parede escuro, a barra de menus fica escura (é o
  sistema).
- winit no X11: uma falha em `set_theme` derruba o processo (`expect`); risco
  baixo.
- Wayland: as decorações do cliente não seguem o tema sem a feature
  `wayland-csd-adwaita`.
- Voltar para a 0.6.2 e salvar regrava o `config.json` sem `theme`,
  `bar_mode` e `alert_dot`.
- O inspetor JSON e o I/O do Docker mantêm o formato da fonte.

### Validação pendente

- Desktop Linux real (VM Omarchy aarch64), pendente desde a v0.6.0. Ubuntu é
  coberto só pelo CI.
- Hardware Intel e versões antigas do macOS.

## Resolvidas desde o registro

Conferidas na `main` em 3c782bb:

- A cor de erro está unificada em `bad`: Console, Conta, Revisão/Manutenção e
  Administração (#14, NB #4).

  atraso saiu (#18).

  F5 do grupo F do #18.

  (#16), com a ressalva V2.
- O "settle 3 s fixo" anotado no #18 é um teto de 3 s num laço de poll, não
  uma espera fixa (`src/operations_ui.rs:997-1004`). Não há o que corrigir.
