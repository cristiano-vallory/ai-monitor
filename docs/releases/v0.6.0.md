# AI Monitor v0.6.0 — Linux (Ubuntu e Omarchy)

Primeira versão com suporte a Linux, por fases: (1) janela egui + Secret Service
no chaveiro; (2) ícone de bandeja StatusNotifierItem com painel sob demanda e
instância única via D-Bus; (3) backend `systemd --user` para `ai-memory.service`;
(4) empacotamento `.deb` + `PKGBUILD` desta release. O macOS permanece
funcionalmente inalterado.

## Instalação

- **Ubuntu ≥ 22.04** (x86_64 ou aarch64): `sudo apt install ./ai-monitor_0.6.0_<amd64|arm64>.deb`
  → `ai-monitor` no menu de aplicativos ou no terminal.
- **Omarchy 4 / Arch**: baixe o `PKGBUILD` desta release e rode `makepkg -si`
  (baixa o tarball verificado por sha256 e instala).
- **Tarball manual**: `tar -xzf ai-monitor-0.6.0-linux-<arch>.tar.gz` →
  `./ai-monitor` (precisa das bibliotecas listadas no `.deb` Depends).

Requer um host de bandeja StatusNotifierItem: Ubuntu usa a extensão
AppIndicator (ativa por padrão); Omarchy usa o tray da barra. Sem tray, o app
abre a janela e encerra ao fechar. `gnome-keyring` é recomendado para guardar
o Bearer. Autostart não é instalado: no GNOME use "Aplicativos de inicialização";
no Hyprland/Omarchy, adicione `exec-once = ai-monitor` em
`~/.config/hypr/autostart.conf` (forma geral de autostart do Hyprland; o local
exato preferido pelo Omarchy não foi verificado nesta versão).

## Limitações

Sem validação em desktop real ainda — o teste na VM Omarchy acontece após a
release, por decisão do usuário; Ubuntu é coberto somente pelo CI (Xvfb headless
+ sway headless). Desinstalar: `sudo apt remove ai-monitor` ou
`sudo pacman -R ai-monitor-bin`.
