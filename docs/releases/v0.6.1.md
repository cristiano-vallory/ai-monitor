# AI Monitor v0.6.1 — correções do port Linux

- Identificadores migrados de `io.github.cristianovallory` para
  `io.github.cristiano_vallory` (sublinhado: hífen é inválido em interface
  D-Bus). **Tokens migram automaticamente na primeira leitura**: a entrada
  antiga é copiada para o identificador novo e removida em seguida; se a
  cópia falhar, o token ainda é devolvido.
- Instância única com limite de 5 s no encaminhamento de `Show()` — uma
  instância travada não pendura o segundo lançamento. Atenção durante a
  atualização: um 0.6.0 rodando e um 0.6.1 não se reconhecem como a mesma
  instância (nome D-Bus mudou) — feche o antigo antes de abrir o novo.
- Chaveiro Linux com tempo limite de 120 s, deduplicação entre coleções
  Secret Service e resposta a erro consistente. Depois do aviso de tempo
  esgotado, a operação pode ainda concluir em segundo plano (por exemplo, se
  o pedido de senha for respondido tarde): confira o estado com "Carregar
  Bearer" antes de repetir. Se o token existir com os dois identificadores,
  a cópia antiga só é removida no próximo salvar ou esquecer.
- Classificação Docker Engine exclui processos rodando em contêiner.
- Janela sob demanda zera a navegação pendente após falha de abertura.
- systemd: inspect inclui ExecStartPre/Post, ExecReload e ExecStop(Post).
- Empacotamento: `.deb` sem `libwayland-egl1-mesa`, `PKGBUILD` com
  `hicolor-icon-theme` e mantenedor; pipeline com concorrência e
  publicação via script validado.
