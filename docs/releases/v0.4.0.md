# AI Monitor v0.4.0 — revisão e manutenção

O novo painel **Administrar memória** permite revisar propostas/evidências e
aprovar ou rejeitar mudanças; cancelar/expirar handoffs; preparar auditoria,
curadoria, retenção e embeddings; reconsolidar sessões e registrar feedback.
Inclui backup privado, exportação OKF, checkpoints e restauração de páginas.

Cada escrita exige prévia/plano e confirmação vinculada à conexão e ao objeto.
Não há repetição automática após falhas. Backups usam arquivo novo com permissão
0600; não são publicados nem copiados para o repositório. Operações com providers
podem gerar cobrança. Não houve manutenção sobre dados reais na validação.

A API de reconsolidação usa o ID global da sessão: o projeto escolhido no painel
não limita o destino. A expiração de handoffs mostra amostra, pois a API não tem
dry-run. Consulte o [guia administrativo](../ADMINISTRATION.md) antes de executar.

## Instalação

Baixe `AI-Monitor-0.4.0-macos-universal.dmg` e o checksum correspondente. Encerre a
versão anterior na barra de menus, abra o DMG, arraste o app para Aplicativos,
ejete e abra o app. Não precisa de Rust, Cargo ou Xcode. ai-memory e Docker são
fontes externas; administração depende das permissões e configuração do servidor.

Universal Apple Silicon/Intel, mínimo declarado macOS 12.0. Testes locais em
Apple Silicon e Intel via Rosetta; sem homologação em Intel físico/macOS antigo.
**Assinatura ad hoc, sem Developer ID e sem notarização Apple**; instruções de
abertura em [INSTALL.md](../../INSTALL.md).

```sh
shasum -a 256 -c AI-Monitor-0.4.0-macos-universal.dmg.sha256
```
