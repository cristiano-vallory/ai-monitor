# AI Monitor v0.2.0 — macOS Universal

Primeira distribuição do AI Monitor pronta para instalar, sem compilar Rust.

## Download e instalação

Baixe **AI-Monitor-0.2.0-macos-universal.dmg** em Assets. Abra o disco, arraste **AI Monitor.app** para **Applications / Aplicativos**, ejete o disco e abra o aplicativo. Ele aparece na **barra de menus**, sem janela inicial; clique em **Abrir painel**.

O pacote contém executáveis nativos para **Apple Silicon e Intel**. Não requer Rust, Cargo, Xcode ou Git. Docker Desktop e o servidor ai-memory são instalados separadamente e continuam necessários para os respectivos dados.

## Recursos

- CPU e memória de ai-memory e Docker na barra de menus, mesmo com a janela fechada.
- Painel com histórico de recursos, threads/tarefas, sessões e handoffs abertos.
- Contêineres, imagens associadas e processos locais do Docker Desktop.
- Consultas somente de leitura, com autenticação opcional e token mantido em memória.
- Instalador com instruções e checksum SHA-256.

## Compatibilidade e primeira abertura

O mínimo declarado é **macOS 12.0**. A interface foi validada em Apple Silicon; o executável Intel foi verificado via Rosetta. Hardware Intel e versões antigas do macOS ainda não foram validados. O Docker Desktop possui requisitos próprios.

**Assinatura ad hoc; sem Developer ID e sem notarização Apple nesta release.** Se o macOS bloquear por desenvolvedor não verificado, após tentar abrir acesse **Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim**, confirmando a origem do download. Não desative o Gatekeeper globalmente. Macs gerenciados podem impedir essa exceção.

## Integridade

Baixe também `AI-Monitor-0.2.0-macos-universal.dmg.sha256`. Na pasta com os dois arquivos:

```sh
shasum -a 256 -c AI-Monitor-0.2.0-macos-universal.dmg.sha256
```

O resultado deve indicar `OK`. O checksum não substitui a notarização.

Para atualizar uma instalação existente, encerre o monitor pelo menu antes de substituir o aplicativo. As preferências são preservadas; tokens não são persistidos.
